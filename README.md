# مِقياس

تطبيق ويب للتدريب على اختبار القدرات العامة (قياس)، يشخّص نقاط الضعف على مستوى المهارة وسبب الخطأ، ويبني خطة مذاكرة تتكيّف مع موعد الاختبار.

## المحتوى

- **٢٠٠ سؤال** موزّعة على **٢٥ مهارة** — القسم الكمّي (٢٠ مهارة) واللفظي (٥ مهارات).
- جميع الأسئلة **مؤلَّفة أصلاً** لهذا المشروع على أنماط الاختبار المعلنة رسمياً — لا يوجد أي محتوى منقول.

## المزايا

| | |
|---|---|
| **تشخيص على مستوى المهارة** | كل سؤال مربوط بمهارة ورقة واحدة، والإتقان يُحسب بدقة مرجّحة بالحداثة |
| **تحليل سبب الخطأ** | كل خيار خاطئ موسوم بسببه الجذري، فيظهر التقرير: «٤٠٪ من أخطائك سببها إهمال الإشارة السالبة» |
| **مؤشر السرعة** | يقارن زمن الحل بالزمن المعياري لكل مهارة، ويفرّق بين «لا تعرف» و«تعرف لكن ببطء» |
| **مستوى الثقة** | زر «متأكدة / أخمّن» يفرّق بين الإتقان والحظ |
| **خطة متكيّفة** | تُبنى من الضعف الفعلي حسب المدة المتبقية للاختبار |
| **لوحة المجموعة** | تحليل مجمّع لعدة طالبات عبر كود مشاركة نصّي — بلا حسابات ولا سيرفر |
| **يعمل بدون إنترنت** | Service Worker + تثبيت على الشاشة الرئيسية (PWA) |

## الخصوصية

كل بيانات الطالبة تُخزَّن في متصفحها فقط (`localStorage`). لا يوجد سيرفر ولا تتبّع ولا حسابات.
كود المشاركة يحمل **ملخّص المهارات فقط** (عدد المحاولات، الصحيح، الزمن الوسيط، عدد التخمينات، أسباب الخطأ) — ولا يحمل الإجابات ولا أي بيانات شخصية.

## الملفات

```
index.html              التطبيق كاملاً (HTML + CSS + JS، بلا اعتماديات)
manifest.webmanifest    إعدادات التثبيت على الجوال
sw.js                   العمل بدون إنترنت
icon-192/512/maskable   الأيقونات
.nojekyll               تعطيل معالجة Jekyll في GitHub Pages
```

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً باسم `miqyas`.
2. ارفع محتويات هذا المجلد كاملة إلى الفرع `main`.
3. `Settings` ← `Pages` ← Source: `Deploy from a branch` ← Branch: `main` / `root` ← Save.
4. الرابط يصبح: `https://<اسم-حسابك>.github.io/miqyas/`

بعد أول فتح، يمكن للطالبة إضافة التطبيق إلى شاشة جوالها الرئيسية ليعمل كتطبيق مستقل وبدون إنترنت.

## التحديث لاحقاً

عند تعديل الأسئلة أو المزايا: ارفع `index.html` الجديد، وارفع رقم النسخة في `sw.js` (`miqyas-v2` ← `miqyas-v3`) حتى تصل النسخة الجديدة لمن ثبّتوا التطبيق.
